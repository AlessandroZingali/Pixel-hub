🎮 Pixel Hub

Un hub web ispirato a Steam per acquistare, gestire e scaricare videogiochi. Progetto universitario per l'esame di Linguaggi per il Web.

🇮🇹 Italiano

🚀 Panoramica

Pixel Hub è una piattaforma web in stile "Steam" progettata per consentire agli utenti di esplorare, acquistare e scaricare videogiochi. Il progetto è stato sviluppato come elaborato d'esame per il corso di Linguaggi per il Web, con l'obiettivo di dimostrare l'implementazione delle principali tecnologie e architetture web (front-end e back-end).

✨ Caratteristiche Principali

🛒 Catalogo & Store: Esplora un vasto catalogo di giochi con schede dettagliate, generi e prezzi.

💳 Acquisto e Carrello: Sistema di gestione del carrello per simulare o elaborare l'acquisto di titoli digitali.

📚 Libreria Personale: Dashboard utente per accedere ai giochi posseduti e avviare il download.

👤 Gestione Utente: Autenticazione (Login/Registrazione) e profilo utente personalizzato.

📱 Interfaccia Responsive: Design moderno sviluppato secondo gli standard del web.

🛠️ Tecnologie Utilizzate

Front-End: XHTML (Strict), CSS3, JavaScript.

Back-End: PHP.

Database: MySQL.

Server Locale: XAMPP (Apache + MySQL).

⚙️ Installazione e Avvio

Scarica e installa XAMPP.

Clona il repository all'interno della cartella htdocs di XAMPP:

cd C:/xampp/htdocs  # (o la directory htdocs corrispondente sul tuo SO)
git clone https://github.com/AlessandroZingali/Pixel-hub.git


Avvia i moduli Apache e MySQL dal Pannello di Controllo di XAMPP.

Importa il database (file .sql presente nel progetto) tramite phpMyAdmin (http://localhost/phpmyadmin).

Apri il browser e naviga all'indirizzo http://localhost/Pixel-hub.

🇬🇧 English

🚀 Overview

Pixel Hub is a Steam-like web platform designed for users to browse, purchase, and download video games. This project was developed for the Web Languages university course, demonstrating core front-end and back-end web development practices.

✨ Key Features

🛒 Storefront & Catalog: Browse a rich catalog of games with detail pages, genres, and pricing.

💳 Cart & Checkout: Cart management system to process digital game purchases.

📚 User Library: Dedicated library dashboard where users can access and download their owned titles.

👤 User Management: Authentication system (Login/Register) and customizable user profiles.

📱 Responsive UI: Modern web interface built adhering to web standards.

🛠️ Tech Stack

Front-End: XHTML (Strict), CSS3, JavaScript.

Back-End: PHP.

Database: MySQL.

Local Server: XAMPP (Apache + MySQL).

⚙️ Getting Started

Download and install XAMPP.

Clone the repository into your XAMPP htdocs directory:

cd C:/xampp/htdocs  # (or equivalent htdocs directory on your OS)
git clone https://github.com/AlessandroZingali/Pixel-hub.git


Start the Apache and MySQL modules from the XAMPP Control Panel.

Import the database (.sql file provided in the repository) via phpMyAdmin (http://localhost/phpmyadmin).

Open your browser and navigate to http://localhost/Pixel-hub.
